WMK Zombie Arena — Áudio de acertos e headshots

Manual do jogador e do desenvolvedor • v1.8.2 • Walney Moreira Klein — walneyk@hotmail.com

1. Que som toca?

EventoEfeito
DisparoPerfil da arma (já existente em audio.js)
Acerto no corpoConfirmação breve gameAudio.hit()
Acerto na cabeçaSom duplo e agudo gameAudio.headshot()
Eliminação sem headshotConfirmação gameAudio.kill()
Acerto em parede/objetoImpacto discreto gameAudio.wallImpact()
Morte do zumbiEfeito gameAudio.zombieDeath()

Os efeitos são originais e sintetizados pelo navegador, não são arquivos copiados de CS 1.6 ou outros jogos.

2. Como o tiro reconhece um headshot?

O motor usa o THREE.Raycaster para descobrir o primeiro objeto atingido. As malhas botHead e botHelmet contam como cabeça. O dano é weapon.damage * weapon.headMultiplier quando o disparo acerta essa região; os valores são fictícios e destinados ao balanceamento do jogo. Dano, som e partículas são sistemas separados.

const head = ['botHead', 'botHelmet'].includes(hit.object.name);
bot.health -= weapon.damage * (head ? weapon.headMultiplier : 1);
if (head) headshotAny = true;

3. Evitar sons repetidos

Uma escopeta lança vários raios em um único disparo. O código agrupa os resultados e toca um único som de feedback por tiro. Quando existe headshot, ele tem prioridade sobre o som de eliminação e acerto comum.

if (headshotAny) gameAudio.headshot();
else if (killedAny) gameAudio.kill();
else if (hitAny) gameAudio.hit();
else if (wallHit) gameAudio.wallImpact();

4. Como ajustar o som

Abra audio.js. As funções hit, headshot e kill usam Web Audio API e envelopes de frequência, duração e volume. Ajuste pitch para mudar o tom e volume para o volume de cada efeito. Teste com fones e volume baixo.

5. Usar sons próprios

Adicione arquivos licenciados por você em assets/audio/ e invoque gameAudio.sample('assets/audio/meu-headshot.ogg', .35) no lugar do efeito sintetizado. Para sons frequentes, é melhor pré-carregar e reutilizar os buffers, evitando atrasos e buscas repetidas.

6. Teste

Inicie pelo Live Server, libere o áudio clicando em Iniciar, mire na cabeça de um zumbi e compare com o acerto no corpo. Use F12 → Console para verificar erros. Confira também o botão de habilitar som e o controle de volume do menu.
