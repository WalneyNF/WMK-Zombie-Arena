WMK Zombie Arena — Publicar jogo completo

Autor: Walney Moreira Klein — walneyk@hotmail.com

O site mostra a demonstração porque os arquivos do jogo completo não foram enviados ao repositório. Este pacote contém os arquivos necessários.

  1. Extraia todos os arquivos do ZIP para uma pasta.
  2. Execute PUBLICAR-GITHUB.bat nessa pasta.
  3. Se solicitado, autentique-se no GitHub.
  4. No repositório, abra Settings → Pages e selecione GitHub Actions.
  5. Confira Actions. Quando a publicação terminar com sucesso, abra o jogo e pressione Ctrl+F5.

O arquivo BAT usa o Git instalado no Windows. Não é possível executar um BAT a partir de uma página web.
