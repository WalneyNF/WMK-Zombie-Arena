WMK Zombie Arena — Modelos do Blender e prefabs

Autor: Walney Moreira Klein — walneyk@hotmail.com · v1.7.0

Objetivo

Substituir objetos geométricos provisórios por modelos 3D próprios, com geometria e materiais detalhados. A importação aceita GLB; outros formatos devem ser convertidos no Blender.

Blender → Jogo

  1. Modele usando metros e aplique escala/rotação (Ctrl+A).
  2. Defina UVs, materiais e texturas. Reduza polígonos; prefira GLB compacto.
  3. File → Export → glTF 2.0 → glTF Binary (.glb).
  4. No editor WMK, selecione um objeto e clique Importar modelo .GLB.
  5. O editor oferece uma prévia temporária. Copie o arquivo GLB para assets/models/ com o nome indicado.
  6. O JSON guarda somente o caminho relativo e dimensões do objeto. Publique o JSON e o GLB juntos.

Regra importante

O JSON não incorpora o conteúdo binário do GLB. Sem o arquivo GLB no site, o jogo usa a geometria substituta. A prévia local isolada não sobrevive à reabertura se o arquivo não tiver sido copiado.

Dimensões e colisão

O modelo é normalizado para caber na caixa definida pelo editor. O sistema de colisão ainda utiliza um volume retangular simplificado (AABB). Não trata portas com abertura física nem escadas navegáveis; são funcionalidades futuras.

Prefabs

Selecione um objeto, clique Salvar objeto como prefab. Depois, selecione na lista e clique Inserir prefab. É possível exportar/importar JSON de prefab. Nesta versão cada prefab contém um objeto e sua referência opcional de GLB; prefabs compostos são uma etapa futura.

Desempenho

Prefira menos materiais e texturas pequenas; teste o jogo em PCs modestos; verifique Network/Console (F12) para falhas de carregamento. Não copie assets de terceiros sem licença.
