Manual do Arsenal Studio — v1.8.3

Abrir editor · Voltar ao FPS

1. Objetivo

Uma arma comunitária é um documento JSON declarativo: nome, munição, recarga, dano fictício, tipo de disparo, aparência e arquivo opcional GLB. O navegador nunca deve executar JavaScript vindo desse JSON.

2. Criar uma bazuca no editor

  1. Abra Arsenal Studio e selecione o exemplo Bazuca WMK.
  2. Altere nome, capacidade, dano, tempo entre disparos e raio de explosão.
  3. Clique Salvar no jogo.
  4. Abra novamente index.html, inicie a partida, tecle B e depois 9.
  5. Compre a arma fictícia, feche o menu e teste disparos no mapa de treino.

3. Como o disparo funciona

Armas de raycast verificam uma interseção imediata. Armas com mechanic=projectile criam uma entidade 3D que se desloca por delta time. Cada movimento verifica a colisão entre a posição anterior e a nova posição. A explosão consulta inimigos dentro de um raio e calcula dano por distância. O efeito de luz/partículas é separado da regra de dano. Todos os valores são de balanceamento de jogo, não especificações reais.

damageAtDistance = damage * max(0, 1 - distancia / raio)

4. Modelar no Blender

  1. Crie a malha fictícia do tubo, empunhadura e detalhes usando primitivos.
  2. Separe objetos logicamente e use nomes claros como Corpo, Mira e Suporte.
  3. Aplique escala/rotação (Ctrl+A) e revise o ponto de origem.
  4. Exporte em glTF 2.0, formato GLB, com materiais simples e texturas compactas.
  5. Coloque o arquivo no projeto em assets/models/minha-bazuca.glb.
  6. No editor, indique o mesmo caminho e ajuste a escala. Salve o JSON.

O arquivo JSON não incorpora automaticamente o GLB. Ao distribuir o mapa/jogo, envie ambos e mantenha os caminhos relativos.

5. Exemplo JSON

{"id":"bazuca_wmk","name":"Bazuca WMK","mechanic":"projectile","category":"special","magazine":1,"reserve":8,"damage":140,"projectileSpeed":23,"blastRadius":4.5,"reload":2.7,"modelPath":"assets/models/minha-bazuca.glb"}

6. Limitações e segurança

O editor ajusta parâmetros e visualização 3D, mas ainda não edita polígonos, UV, rigging ou animações. O armazenamento local depende da origem do navegador; instalar arma em outro computador exige importar JSON e disponibilizar o GLB. No futuro multiplayer, o servidor deve validar as definições permitidas; não se deve aceitar dano arbitrário enviado pelo cliente. O número de armas é limitado para proteger desempenho.

7. Exercícios

  1. Criar uma arma de tiro instantâneo e compará-la com o projétil.
  2. Testar duas capacidades de munição e medir tempo de recarga.
  3. Construir e importar seu próprio GLB no Blender.
  4. Exportar JSON e reinstalar em outro navegador.
