Manual técnico: armas, recarga e áudio

Documentação v1.8.1 • Código MIT • 22/11/2026

Esta versão usa efeitos procedurais gerados pelo Web Audio API. São sonorizações de jogo, não reproduções de gravações comerciais. O áudio só inicia após clicar em Iniciar, conforme as restrições do navegador.

1. Onde editar cada parte

ArquivoResponsabilidade
weapons.jsCadastro, dano fictício, preço, slot, munição, recarga, cadência, dispersão, skins
game.jsRaycast, animação, inventário, inputs, gerenciamento de jogo e gatilhos de som
audio.jsPerfis de som, efeitos procedurais, volume, samples opcionais e cache
index.html / style.cssHUD, menu, controles e estilos

2. Criar uma arma

Abra weapons.js e insira uma nova entrada em WEAPONS, utilizando a função auxiliar gun(...) já existente. Exemplo de pistola fictícia:

treino: gun('WMK Treino','pistol','secondary',450,
  18,108,24,.19,1.4,.008,.28,
  {type:'semiauto',headMultiplier:1.8,color:0x506c58}),

Propriedades: magazine é capacidade; reserve é a reserva; damage é dano abstrato; cooldown é intervalo em segundos; reload é duração da recarga; spread é dispersão; movementSpread aumenta dispersão ao caminhar; pellets representa múltiplos raios para escopetas; slot define principal, secundária ou faca; type distingue semiautomático e automático. O menu gera as opções a partir de WEAPONS.

3. Dando sons próprios à arma

Você pode adicionar uma propriedade audio a qualquer arma após a criação. Use arquivos próprios ou com licença compatível, salvos sob assets/audio/:

WEAPONS.treino.audio = {
  shot: 'assets/audio/treino-tiro.ogg',
  reload: 'assets/audio/treino-recarga.ogg'
};

Se o som não carregar, o motor usa o efeito sintético padrão. Os formatos aceitos na configuração são ogg, mp3 e wav; o suporte de reprodução varia conforme o navegador. Nunca aponte para endereços externos não confiáveis ou copie áudio de jogos comerciais sem licença.

4. Integração de áudio no jogo

import { gameAudio } from './audio.js';
// Após ação explícita do usuário (botão INICIAR):
gameAudio.unlock();
// No disparo validado:
gameAudio.shot(currentWeapon());
// Ao iniciar uma recarga:
gameAudio.reload(currentWeapon());
// Quando a animação/temporizador de recarga termina:
gameAudio.reloadComplete();
// Zumbi próximo:
gameAudio.zombie(distanciaAteJogador);

O volume mestre e o estado ligado/desligado ficam em localStorage sob wmk_zombie_audio_v1. Os sons dos zumbis têm limitação de frequência para evitar dezenas de vozes simultâneas e consumo excessivo de CPU.

5. Como testar

  1. Abra o jogo em HTTP local, clique Iniciar e permita o mouse.
  2. Atire usando pistola, AWP e escopeta; compare timbres.
  3. Use R para recarregar; teste pente cheio, pente vazio e troca durante a recarga.
  4. Espere os zumbis se aproximarem; confirme ruídos e dano sonoro.
  5. Desative áudio e confira que o jogo continua funcionando.
  6. No Console (F12), confirme que não há falhas de importação nem arquivos de áudio ausentes.
