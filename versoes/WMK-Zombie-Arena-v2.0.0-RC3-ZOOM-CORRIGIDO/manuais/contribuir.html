Guia de contribuição: mapas, armas, sons e código

Documentação v1.8.1 • Código MIT • 22/11/2026

1. Como colaborar

  1. Faça um fork do repositório e crie uma branch feature/minha-melhoria.
  2. Abra o projeto via Live Server ou py -m http.server 5500.
  3. Faça alterações pequenas, explique como testar e preserve as funcionalidades existentes.
  4. Atualize a documentação HTML correspondente.
  5. Abra uma Pull Request com capturas, roteiro de teste e descrição da licença dos assets.

2. Conteúdos aceitos

TipoFormatoRequisitos
MapaJSON + miniatura WebP/PNGSpawns válidos, limites de objetos, sem código executável
Modelo BlenderGLB/glTFOrigem, licença, escala, orientação, colisão e LOD documentados
ArmaEntrada em weapons.js + GLB opcionalBalanceamento fictício, testada nos 3 slots, som original/licenciado
ÁudioOGG/MP3/WAVProva de autoria/licença, volume equilibrado e sem clipping
CódigoHTML/CSS/JSSem segredos/credenciais; sem regressões e sem dependências desnecessárias

3. Checklist de Pull Request

[ ] Rodou com servidor HTTP local
[ ] Console sem erros de JS
[ ] Testei atirar, recarregar, trocar arma e pausar
[ ] Testei mapa customizado / salvar JSON (se aplicável)
[ ] Não copiei conteúdo de CS, Zula ou jogos comerciais
[ ] Assets próprios ou com licenças verificadas
[ ] Atualizei manuais HTML e versão
[ ] Descrevi impacto em desempenho e segurança

4. Convenções sugeridas

Arquivos em kebab-case; IDs persistentes; configurações de conteúdo em JSON; importações modulares; validação antes de importar objetos e mapas. Evite remover recursos sem avisar e evite mudanças de layout que impossibilitem o uso em 1366×768.

5. Contribuições para o multiplayer

Primeiro construa testes de protocolo e validação no servidor. Nunca aceite do cliente valores de vida, dano ou pontuação como autoridade. Não inclua tokens secretos no código publicado do Pages.

6. Licença

O código autoral está sob MIT. Bibliotecas, modelos, texturas e áudios podem ter licenças próprias: documente cada recurso. A contribuição deve ser autorizada por seu criador.
