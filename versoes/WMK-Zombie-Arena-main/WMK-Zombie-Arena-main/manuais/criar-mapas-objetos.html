WMK — Guia de criação de mapas e objetos FPS

Mapas originais inspirados em princípios de Counter-Strike, Zula e shooters táticos. Para criadores iniciantes e desenvolvedores. Walney Moreira Klein — walneyk@hotmail.com

1. O que aprendemos com os mapas clássicos

cs_rio: becos estreitos, pátio, casas de tijolos, telhados, portas e janelas criam caminhos alternativos e encontros imprevisíveis. de_dust2: rotas claras e disputas por áreas de passagem. cs_office: salas e corredores, visão curta e combate próximo. O segredo é a composição dos objetos, e não apenas a quantidade. Não reutilize modelos, texturas e mapas comerciais sem licença.

Referências: cs_rio (imagens de referência) · Ferramentas de criação CS2 · Tutoriais clássicos de mapeamento.

2. Biblioteca do editor

3. Criar um mapa interessante em dez etapas

  1. Escolha o tema: vila, fábrica, escola, hospital ou porto.
  2. Desenhe em papel o mapa visto de cima, com começo, destino, duas rotas principais e uma alternativa.
  3. Crie pisos e paredes para definir limites.
  4. Distribua espaços amplos e corredores estreitos sem bloquear todas as passagens.
  5. Adicione construções e volumes; teste a altura do personagem.
  6. Coloque coberturas em pontos de combate, sem favorecer apenas um lado.
  7. Inclua referências visuais (poste, placa, máquina, letreiro) para o jogador se localizar.
  8. Posicione spawn do jogador e spawns dos zumbis em locais seguros e válidos.
  9. Teste no FPS, verifique se os zumbis conseguem se aproximar e se tiros atravessam objetos.
  10. Adicione modelos GLB, revise colisões, exporte JSON e crie uma miniatura.

Importante: o motor atual usa colisões aproximadas por caixas. Escadas, pisos elevados e janelas não têm comportamento físico completo; trate-os como elementos visuais ou de cobertura até implementar física e navegação adequadas.

4. Criar um prefab do zero com o Blender

  1. No Blender, use metros como unidade (1 unidade = 1 metro como convenção do WMK).
  2. Modele um objeto original, por exemplo uma barricada, bancada ou máquina.
  3. Defina a origem (pivô) na base ou centro desejado; aplique rotação e escala com Ctrl+A.
  4. Faça UV Unwrap; use materiais simples e texturas de autoria própria ou com licença apropriada.
  5. Para objetos complexos, produza uma versão low-poly ou uma malha de colisão simplificada.
  6. Exporte File → Export → glTF 2.0, formato GLB, com materiais incorporados.
  7. Copie o arquivo para assets/models/ no projeto, por exemplo assets/models/wmk-barricada.glb.
  8. No editor, selecione uma caixa de tamanho adequado, informe o caminho e pressione Aplicar modelo ao objeto.
  9. Selecione o objeto e clique em Salvar objeto como prefab.
  10. Exporte prefab JSON e mapa JSON; para compartilhar, inclua o arquivo GLB correspondente.
A prévia local de GLB não grava o arquivo dentro do site. O modelo deve existir fisicamente em assets/models/ na versão publicada. Nunca coloque JavaScript executável dentro de JSON comunitário.

5. Exemplo de objeto no mapa

{
  "id": "obj_100",
  "name": "Barricada oficina",
  "type": "cover",
  "x": 3, "y": 0.6, "z": -4,
  "w": 2, "h": 1.2, "d": 0.8,
  "ry": 0,
  "color": "#8e8070",
  "solid": true,
  "model": "assets/models/wmk-barricada.glb"
}

Esse objeto é um membro de objects em um arquivo wmk-zombie-map. O tipo define o padrão da geometria e seu comportamento no editor; model referencia o arquivo 3D. O jogo deve validar os valores recebidos.

6. Como construir seus próprios materiais

Comece com uma paleta de concreto, tijolos, metal oxidado, madeira e vidro. Gere texturas sem marcas comerciais, use um atlas UV para reunir peças pequenas e considere repetição de textura (tiling). O campo color atual altera apenas a cor básica; materiais PBR com mapas normal/roughness são um próximo passo para o renderizador.

7. Boas práticas de jogabilidade

Teste o mapa sem zumbis para validar circulação; depois faça testes com bot. Evite becos sem saída sem intenção, pontos de spawn presos, áreas sem cobertura e linhas de visão que atravessem o mapa inteiro. Mapas de treino precisam de linhas claras de distância e indicação de acerto. Mapas de bombas precisam de rotas equilibradas às áreas de objetivo. Use visibilidade e marcos para orientar o jogador.

8. Otimização para computadores modestos

Reduza materiais distintos e texturas enormes, agrupe geometria estática quando possível, use InstancedMesh para repetição e simplifique colisões. Comece com poucos objetos e aumente monitorando FPS. A cena com muitos GLB diferentes pode ficar pesada: use tamanhos de arquivo e limites por mapa.

9. Como contribuir

Crie ou duplique um mapa, exporte o JSON, envie os GLB originais e a miniatura; informe licença, autoria, modos suportados e instruções de teste. Abra um Pull Request para a branch develop. O catálogo mapas/index.json precisa apontar para o JSON para o jogo encontrá-lo pelo marketplace.
