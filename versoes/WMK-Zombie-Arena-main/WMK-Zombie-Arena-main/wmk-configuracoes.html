Salvar e restaurar dados (JSON)

ATENÇÃO: o save do navegador pode ser perdido! O armazenamento local pode desaparecer ao limpar dados do site, usar aba privada, trocar de navegador/computador ou reinstalar. Exporte backups JSON regularmente e guarde uma cópia fora do navegador.

1. Exportar meu save

Inclui dados WMK disponíveis neste endereço: carteira W$, compras, mapas, layouts e personalizações que tenham sido salvas no navegador. Selecione os registros para baixar.

2. Importar backup

Escolha um JSON exportado por este menu. O arquivo será validado antes de alterar dados. Restaurar substitui os registros correspondentes mas não apaga os que não estiverem no backup.

Nenhum arquivo selecionado.

3. Limitações importantes

Este backup salva dados armazenados neste navegador e origem, não arquivos que estão somente no disco, como modelos GLB, PNGs e outros assets ainda não publicados. Guarde também esses arquivos e os JSONs de mapas exportados individualmente.

Um backup no localhost de porta diferente ou no GitHub Pages é independente: o navegador separa o armazenamento por origem. Importar os dados é o caminho para migrar de uma origem para outra.

Uma versão multiplayer futura precisará de autenticação e saves no servidor; o W$ local serve apenas ao modo offline e não é prova de saldo online.
