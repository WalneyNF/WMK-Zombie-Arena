Espaço de trabalho

Arraste cada painel pela barra superior. Redimensione pelo canto inferior direito. Use × para ocultar e os botões da barra superior para exibir. Escreva um nome e clique em Salvar layout para guardar a disposição. Carregar layout restaura. Há exportação e importação de layout JSON no Arsenal Studio.

Snap

Ative o ímã para encaixe na grade. No editor de mapas é possível configurar o passo. No Arsenal Studio, a translação usa 0,25 unidade, rotação 15 graus, escala 0,1. Os gizmos são do Three.js (TransformControls).

Diferença do Blender

Esses editores não possuem a modelagem completa de vértices, malhas e UV como o Blender. Eles transformam objetos, ajustam parâmetros e importam GLB. Para alterar a geometria, modele no Blender e exporte GLB.

Persistência

Layouts são salvos no localStorage do navegador e não são enviados automaticamente ao GitHub. Armas e mapas são dados separados dos layouts. Exporte backups JSON antes de limpar os dados do navegador.
