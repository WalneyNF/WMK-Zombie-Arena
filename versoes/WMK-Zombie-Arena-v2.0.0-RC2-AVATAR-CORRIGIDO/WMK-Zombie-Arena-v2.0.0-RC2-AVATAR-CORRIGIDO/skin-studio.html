Pintura 2D e UV

A textura usa resolução 512 × 512. Importe o UV exportado do Blender como referência visual para posicionar desenhos.

Skins da arma

Crie uma skin e clique em Salvar skin no jogo. Ela aparecerá no menu B, na arma correspondente.

Camadas e arquivos

Biblioteca de skins locais

As imagens salvas localmente ficam no armazenamento do navegador. Para compartilhar, exporte JSON e PNG e inclua os arquivos no projeto. Cada skin é apenas cosmética.

Materiais e informações

Fluxo recomendado: modele no Blender → faça UV Unwrap → exporte GLB e guia UV → pinte a textura aqui ou em Aseprite/Krita → salve a skin → teste no jogo.

Aprender UV Mapping, materiais e publicação

Este editor pinta mapas de cor (baseColor). Não altera geometria, normal map ou rigging. Para modelos sem UV, use Blender para gerar UVs.
