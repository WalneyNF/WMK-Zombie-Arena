# Bairro Zero — configuração de Dia/Noite e zumbis

Esta versão experimental do gerador 3D permite escolher ciclo automático ou iluminação manual, duração de 5/10/20/40 minutos e zumbis desativados, só à noite ou sempre ativos. A quantidade máxima fica entre 0 e 30.

Abra cidade-viva.html em um servidor local, ajuste as opções, clique em Editar cópia no Map Studio para levar a geometria a editor.html, ou Exportar mapa JSON para obter o arquivo com citySimulation.

A cena possui zumbis geométricos de demonstração andando pela cidade; não há combate, animação completa, navegação por ruas ou integração ao FPS principal nesta etapa. Os controles de iluminação e infestação são do protótipo CV-01, não do modo Sobrevivência oficial.

O ciclo é pausado com o botão Pausar trânsito. A opção de iluminação manual é aplicada pelo seletor. O mapa exportado armazena configurações, mas o FPS atual ainda não interpreta citySimulation.

Para criar outro mapa, altere a semente e use Gerar nova cidade, ou edite uma cópia no Map Studio sem sobrescrever o Bairro Zero.
