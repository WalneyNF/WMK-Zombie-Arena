Manual de publicação no GitHub Pages

WMK Zombie Arena v1.6.0 — Walney Moreira Klein — walneyk@hotmail.com

1. Envie o projeto COMPLETO

O repositório precisa de index.html, style.css, game.js, weapons.js, map-library.js, editor.html, editor.js, editor.css, marketplace.html, marketplace.js, marketplace.css, assets/, mapas/, manuais/ e .github/workflows/pages.yml na raiz.

Ao enviar usando a interface do GitHub, confirme que os arquivos NÃO ficaram dentro de uma pasta extra chamada WMK-Zombie-Arena-v1.6.0.

2. Configurar Pages

Abra Settings → Pages → Build and deployment e selecione GitHub Actions (o projeto inclui o workflow pages.yml). Verifique a aba Actions para possíveis falhas.

3. Abrir o endereço

https://walneynf.github.io/WMK-Zombie-Arena/

4. Conferir

Abra F12 → Network e Console. Confirme status 200 para index.html, game.js, style.css, weapons.js, map-library.js, assets/logo.svg e mapas/index.json. Se aparecer 404, confira letras maiúsculas e a organização no GitHub.

5. Mapas comunitários

O marketplace usa mapas/index.json, que aponta para arquivos JSON individuais em mapas/. O Pages não permite listar automaticamente arquivos da pasta. Para incluir novos mapas, atualize o catálogo e publique novamente.

6. Limitações

GitHub Pages é hospedagem estática: não fornece servidor Node.js, rankings persistentes, autenticação de jogadores, salas 5v5 nem multiplayer em tempo real. A criação de mapas no navegador usa armazenamento local e exportação JSON.

7. Segurança

Valide mapas antes de publicar. Não inclua scripts dentro do JSON. Prefira revisões por pull request; evite aceitar qualquer arquivo sem limites de tamanho e geometria.
